# Developer page artwork

- `headphones.png`: generated transparent illustration. The exact generation prompt is in `headphones.prompt.txt`.
- `deepak.png`: original portrait supplied by Deepak Dumka for his developer card. The circular crop is displayed in Flutter; the source photo is unchanged.
- `shubham.png`: original portrait supplied for Shubham Loshali's developer card. The circular crop is displayed in Flutter; the source photo is unchanged.
- `github.png`: unmodified official GitHub Invertocat white mark from [GitHub's logo assets](https://brand.github.com/GitHub_Logos.zip). Used to identify links to the developers' GitHub profiles. The GitHub name and mark belong to GitHub.

Page backgrounds, borders, ribbons, typography, initials and interactive controls are rendered in Flutter.
